# isfvert

**Projet dormant.** Dernier commit le 2024-01-11, Next 13.4.4, hors LTS depuis longtemps et
jamais patché depuis. Le site est encore en ligne.

## Ce qu'il faut savoir avant d'y toucher

- **Les guidelines de la stack ne s'appliquent pas ici.** Elles décrivent Next 16 :
  App Router, React 19, React Compiler, Base UI. Rien de tout ça n'existe dans ce
  projet, et les suivre produirait du code que la version installée ne comprend pas.
  C'est pourquoi `docs/` ne les référence pas.
- **Ne pas bumper Next à la légère.** Passer de 13 à 16 est une migration majeure,
  pas une mise à jour. Elle se décide, elle ne se fait pas en passant.
- Une modification urgente se fait dans la version en place, en la laissant telle
  qu'elle est.
